# Wi-Fi and local network troubleshooting

## Wi-Fi has no internet access

Check that Wi-Fi is enabled and the correct approved network is selected. Compare connectivity with another approved device in the same location. Reconnect to the network once and check whether a captive portal requires sign-in. If all devices are affected, report a possible network outage. Record location, network name and the time the issue began. Do not reset managed network settings without approval.

## Network changes

DNS server, proxy, firewall and network adapter policy changes require the network or endpoint team. Never connect a corporate device to an unknown hotspot to bypass security restrictions.
