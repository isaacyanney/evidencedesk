# Verdächtige E-Mail und Phishing

## Verdächtige Nachricht melden

Klicken Sie bei einer verdächtigen Phishing-E-Mail keine Links an, öffnen Sie keine Anhänge und antworten Sie nicht. Nutzen Sie die freigegebene Meldefunktion oder kontaktieren Sie das Sicherheitsteam über einen geprüften Kanal. Bewahren Sie die Originalnachricht für die Analyse auf. Wenn Sie bereits geklickt oder Zugangsdaten eingegeben haben, melden Sie dies sofort. Leiten Sie verdächtige Anhänge nicht an Kollegen weiter.

## Verdacht auf Schadsoftware

Wenn ein verdächtiger Anhang ausgeführt wurde, kontaktieren Sie sofort das Sicherheitsteam. Befolgen Sie das interne Verfahren zur Isolation des Geräts. Löschen Sie keine Beweise und nutzen Sie keine ungeprüften Bereinigungsprogramme. Eine Freigabe nach Sicherheitsprüfung ist erforderlich.
