# Software installation and access requests

## Request an application installation

Check the approved software catalog or company portal before requesting an application. Include the application name, business reason, device asset number and required date in the request. Software not in the catalog requires licensing and security review. Administrative installation is performed by the authorized endpoint team. Do not bypass application controls or use personal licenses for company work.

## Request folder access

For a shared folder access request, provide the resource name, required access level and business reason. Approval must come from the resource owner before permissions are changed. Apply least privilege. Do not copy another user's permissions automatically or grant administrator rights as a workaround.
