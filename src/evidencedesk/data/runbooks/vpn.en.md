# VPN connection troubleshooting

## Check an unavailable VPN

Confirm that ordinary websites load before troubleshooting the VPN connection. If the internet connection fails, resolve local Wi-Fi or wired connectivity first. Check the approved service status page for a VPN outage. Restart the VPN client once and reconnect. Record the exact error and time if the connection still fails. Never share a password or an MFA code with support.

## Escalation

Escalate repeated VPN authentication errors to the identity team. Include the device asset number, client version, error text and timestamp. Do not disable endpoint security or change firewall rules to make the VPN connect. Administrative configuration changes require the network team.
