# Softwareinstallation und Zugriffsanfragen

## Anwendung installieren lassen

Prüfen Sie zuerst den freigegebenen Softwarekatalog oder das Unternehmensportal. Geben Sie Anwendungsname, dienstlichen Zweck, Gerätenummer und benötigten Termin an. Software außerhalb des Katalogs benötigt Lizenz- und Sicherheitsprüfung. Administrative Installationen übernimmt das berechtigte Endgeräteteam. Umgehen Sie keine Anwendungskontrollen und nutzen Sie keine privaten Lizenzen für dienstliche Arbeit.

## Ordnerzugriff beantragen

Für Zugriff auf einen gemeinsamen Ordner nennen Sie Ressource, benötigte Berechtigungsstufe und dienstlichen Zweck. Vor einer Änderung muss der Ressourcenverantwortliche zustimmen. Vergeben Sie nur die notwendigen Rechte. Kopieren Sie keine fremden Berechtigungen pauschal und vergeben Sie keine Administratorrechte als Umgehung.
