# Lost phone and MFA recovery

## Recover access after losing a phone

If a phone used for MFA is lost, contact the identity team through an independently verified support channel. Follow the approved identity verification procedure before changing authentication methods. An authorized administrator can revoke existing sessions and reset registered MFA methods after verification. The user must register a new authenticator. Never approve an unexpected sign-in notification.

## Security escalation

Unexpected MFA approval requests may indicate account compromise. Deny the request and contact the security team immediately using a verified channel. Do not send passwords, one-time codes or recovery codes in a ticket. Support cannot bypass identity verification because a request is urgent.
