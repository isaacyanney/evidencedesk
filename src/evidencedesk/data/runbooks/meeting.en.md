# Meeting room audio and display

## No sound or microphone in a meeting

Check that the meeting application uses the room speaker and microphone rather than the laptop devices. Confirm mute is off in both the application and room controls. Check the USB connection or approved room dock. Run the application's audio test before joining again. Avoid connecting multiple active microphones in the same room because this can cause feedback.

## No image on the room display

For a blank meeting room display, confirm the display is powered on and the correct input is selected. Reseat the HDMI or USB-C cable and check the approved dock. Use the operating system's display settings to detect the external screen. Do not install unapproved display software or change room administrator settings.
