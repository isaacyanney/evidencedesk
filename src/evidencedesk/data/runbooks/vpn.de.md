# VPN Verbindung prüfen

## VPN verbindet sich nicht

Prüfen Sie zuerst, ob normale Webseiten erreichbar sind. Wenn die Internetverbindung fehlt, prüfen Sie zuerst WLAN oder Netzwerkkabel. Prüfen Sie die freigegebene Statusseite auf eine VPN-Störung. Starten Sie den VPN-Client einmal neu und verbinden Sie sich erneut. Notieren Sie bei weiteren Fehlern die genaue Meldung und die Uhrzeit. Geben Sie niemals ein Passwort oder einen MFA-Code weiter.

## Weitergabe

Wiederholte VPN-Anmeldefehler gehen an das Identitätsteam. Übermitteln Sie Gerätenummer, Client-Version, Fehlermeldung und Zeitpunkt. Deaktivieren Sie keine Sicherheitssoftware und ändern Sie keine Firewall-Regeln. Administrative Änderungen übernimmt das Netzwerkteam.
