# Handy verloren und MFA wiederherstellen

## Zugang nach Verlust des Handys

Wenn das für MFA genutzte Handy verloren ist, kontaktieren Sie das Identitätsteam über einen unabhängig geprüften Supportkanal. Vor Änderungen muss die Identität nach dem freigegebenen Verfahren geprüft werden. Danach kann ein berechtigter Administrator bestehende Sitzungen widerrufen und MFA-Methoden zurücksetzen. Registrieren Sie anschließend einen neuen Authenticator. Bestätigen Sie keine unerwartete Anmeldeanfrage.

## Sicherheitsvorfall

Unerwartete MFA-Anfragen können auf einen kompromittierten Zugang hinweisen. Lehnen Sie die Anfrage ab und kontaktieren Sie sofort das Sicherheitsteam über einen geprüften Kanal. Schreiben Sie keine Passwörter, Einmalcodes oder Wiederherstellungscodes in ein Ticket. Auch bei dringenden Anfragen darf die Identitätsprüfung nicht umgangen werden.
