# Printer offline and stuck print jobs

## Check an offline printer

For an offline printer, check that it is powered on, has paper and shows no device error. Confirm the correct approved printer is selected and that the computer is connected to the expected network. Check the print queue for paused jobs. Remove only your own failed print job if permitted. Restart the printer once if local procedure allows. Record the printer name and displayed error for support.

## Administrator boundary

Driver installation and print spooler service changes require the endpoint support team. Do not download printer drivers from unapproved websites. Shared print queue changes can affect other users and require authorization.
