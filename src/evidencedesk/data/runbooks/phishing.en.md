# Suspicious email and phishing response

## Report a suspicious message

Do not click links, open attachments or reply to a suspected phishing email. Use the approved phishing-report button or contact the security team through a verified channel. Preserve the original message for analysis. If you clicked a link or entered credentials, report this immediately and follow the security team's instructions. Do not forward suspicious attachments to colleagues.

## Possible malware execution

If a suspicious attachment was executed, contact security immediately. Follow the organization's incident response procedure for isolating the device. Do not delete evidence, run unapproved cleanup tools or claim the device is clean without security review.
